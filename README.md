# Mohan Paudel's Educational Resource Platform 📚

A modernized, premium educational platform featuring interactive quizzes, literature collections, and science resources. Built with a focus on high-quality UI/UX, accessibility, and centralized data management.

## 🌟 Key Features

- **Centralized Design System**: Robust CSS architecture with global variables for easy maintenance.
- **Universal Dark Mode**: Intelligent theme switching with local storage persistence across all pages.
- **Interactive Quiz Engine**: Dynamic quiz delivery with filtered topics, difficulty levels, and instant feedback.
- **Resource Search**: Real-time filtering on the landing page to quickly find learning materials.
- **Responsive & Accessible**: Optimized for all devices, from mobile phones to high-resolution desktops.
- **Premium Aesthetics**: Smooth micro-animations, glassmorphism effects, and curated typography.

## 📂 Project Structure

```text
.
├── index.html              # Main Landing Page
├── css/
│   └── styles.css          # Centralized Design System
├── js/
│   ├── main.js             # Navigation, Search & Theme Logic
│   ├── script.js           # Core Quiz Engine
│   └── questions.json      # Centralized Question Database
└── resources/              # Educational Sub-pages
    ├── computer.html       # Computer Science Quiz
    ├── chemistry/          # Specialized Chemistry Modules
    ├── literature/         # Stories, Poems, and Essays
    └── language/           # Nepali and English Grammar
```

## 🛠️ Technology Stack

- **Frontend**: Vanilla HTML5, CSS3 (Modern Flexbox/Grid), JavaScript (ES6+).
- **Data**: JSON-based asynchronous content loading.
- **Performance**: Intersection Observer API for animations and throttled scroll events.
- **Persistence**: Browser LocalStorage for user preferences.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/paudelmohan27/educational-resources.git
   ```
2. **Launch**: Simply open `index.html` in any modern web browser or serve via:
   ```bash
   python -m http.server 8000
   ```
